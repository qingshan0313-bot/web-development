Frame · 素材工具台（可部署的 Web 应用）

本地开发与调试
Mac：双击「打开工具台.command」启动源码开发服务并打开浏览器；完整步骤见「Mac开发说明.md」。Windows 仍可使用原有命令。
当前阶段仅在本地开发、调试，尚未部署发布；最终目标是通过 Google AI Studio 发布到 Cloud Run。
只需安装 Node.js，在本目录打开终端即可运行以下命令。无需安装 npm 运行依赖；所需视频库已包含在项目中，无需 npm install。

npm run dev
启动本地 HTTP 开发服务，直接读取 src。用浏览器打开终端显示的地址；修改源码后刷新页面即可查看，不需要先构建。

npm run build
构建应用，将可发布的静态文件输出到 dist。

npm run preview
启动本地 HTTP 服务预览 dist。请先运行 npm run build；修改源码后需重新构建，才能在此预览中看到更新。

npm start
生产启动命令，自动构建并提供 dist。监听 0.0.0.0 和平台注入的 PORT；未设置 PORT 时使用 8080。
日常本地调试继续使用 npm run dev，本地预览继续使用 npm run preview。

建议使用 Chrome / Edge 开发和体验。HTTP 服务保持终端运行，按 Ctrl+C 停止。

附加快速体验
双击「打开工具台.cmd」，或用 Chrome / Edge 打开 dist/index.html，可快速体验已构建版本。
此方式无需 Node.js、无需联网、无需登录，可使用图片、字幕及 MP4/WebM 等功能。ProRes MOV 使用 Web Worker，不能通过 file:// 双击模式导出；请运行 npm run dev、npm run preview，或使用已部署的 HTTP/HTTPS 网站。
解压 ZIP 后再打开，不要只移动 index.html。
日常开发调试建议使用 npm run dev；双击打开不会直接反映 src 的修改。

已实现的十一个工具
首页导航为「工作台」，保留加大的四格图标，顶部入口为 QS STUDIO，页脚显示 11 个工具。侧边栏分类带缓入缓出的展开动画；返回工作台时保留已展开的分类。「批量混剪」位于独立的「批量制作」分类；「我的收藏」展开已收藏工具。
首页「开始创作」平滑滚动到工作台工具列表，主图移出视口；顶部「QS STUDIO」可返回总览，点击左上角「Frame 素材工具台」平滑滚回首页顶部并显示主图。
• 视频居中：批量导入视频，选择纯色或图片背景，调整画幅与占比，导出 MP4、MOV 或 WebM；保留原声，多文件打包 ZIP。MOV 默认使用透明留边，原视频画面保留，可关闭透明选项。
• 批量混剪：一个片头接一个成片，支持单片头搭配多成片、全组合和顺序配对；逐素材裁剪、调音量，预览衔接后批量导出。
• 批量重命名：前缀、日期、序号、原名组合，可逐项修改，导出 ZIP 副本，不改动原文件。
• 智能命名：本地读取视频/图片信息，按字段和模板命名；可选 AI 抽帧分析，支持统一修改、手动字段保护、ZIP 副本与 CSV 清单。
• 字幕编辑：按行生成时间轴，手动编辑、导入和导出 SRT，检查时间重叠与空字幕。
• 对话打字动画：编排台词、输入节奏、背景与键盘，预览时间线，导出无声 MP4、MOV、WebM、当前帧 PNG 或项目 JSON。
• 数字计时器：1–60 秒倒计时，支持横竖屏、自定义颜色和文字，导出无声 MP4、MOV 或 WebM。
• 选项动画：设置问题、选项和答案揭晓时间，导出无声 MP4、MOV 或 WebM。
• 相纸图：上传照片，居中裁切，设置注释、署名与颜色，导出 PNG。
• 对话气泡：左右方向、字体大小与颜色，导出透明 PNG。
• 图片取色：提取代表色、点击图片精确取色、复制 HEX、导出 PNG 色卡。

智能命名：字段、AI 分析与下载
1. 从「素材与效率 → 智能命名」进入，导入本地视频或图片，每批最多 100 个。尺寸、比例、时长和缩略图在本地读取；视频同时显示 1080p 和 32 MB 状态作为参考，不会因未达标拒绝添加。
2. 原站的国家、性别、角色类别、素材形式、内容类目、创意人、素材类型、产品、营销功能、精致度、风险分类、渠道、女性向分类、竞品名、自定义文字均保留，另提供画面语言字段。
   在「统一修改」勾选并填写字段后，所选范围内的待分析素材会自动预填。分析完成后优先采用识别结果，未识别的字段保留预填值。「应用统一修改」可直接批量更改素材。单独编辑某条字段后自动保护，统一修改和后续 AI 不会覆盖；可逐字段、逐条或对所选素材解除保护。
   导入时，文件超过 32 MB 或视频分辨率不是竖屏 1080 × 1920、横屏 1920 × 1080 时，可选择使用浏览器内置 FFmpeg 处理副本，或继续使用原件。视频会等比缩放铺满画面，比例不同时居中裁切；处理后的视频为 MP4。
   全部 16 个字段旁都有「+ 新建」：填写标签代码和可选含义，点击「保存并使用」即可填入当前字段，并加入该字段的共享下拉选项。统一修改和逐条素材均可使用，标签保存在当前浏览器，刷新后仍在。
   「管理字段选项」支持添加、删除、恢复，以及填写代码的含义；相同代码（忽略大小写）更新其说明，每个字段最多 100 个标签。AI 会接收这些选项说明，无法确定的业务代码留空供手动填写。
   标题旁的「命名说明」可打开小窗口，查看序号规则、当前命名结构、字段标签和素材规格说明；字段标签会同步显示最新的自定义内容。
   已按提供的命名规范补充现有选项的中文含义和字段提示，仍保持 16 个字段。语言 / 国家中的 US 表示英语、MN 表示闽南语；剪辑人缩写与创意人分开记录，精致度表示制作方式，选填字段可留空。新增的是同一字段内的 RU、hunjian、CSH、TT、DSP 选项，不增加表单字段或改变命名顺序。
   首次更新会补充原来只有代码的默认说明，保留已自定义的含义、标签和主动清空的选项列表；旧代码也保留，便于继续使用原有命名。
3. 设置日期、命名缩写、起始序号、位数、分隔符和模板，实时查看最终文件名；保留原扩展名，清理非法字符，重复名称自动加编号。可单独改最终文件名，或恢复模板生成。
   命名比例、时长、分辨率可手动改，不修改原视频物理参数。模板字段帮助可点击插入占位符，未知字段或无效日期会明确提示并暂停导出。
4. 可选 AI 分析：填写自己的 API Key、模型 ID 和 Base URL。默认火山方舟套餐接口 https://ark.cn-beijing.volces.com/api/plan/v3，模型需使用当前账号已启用且支持多图理解的模型 ID 或 ep- 接入点 ID；未预置付费账号。
   勾选允许发送图片后才可分析所选素材。每个视频均匀抽取 8 帧、每张图片提取 1 帧，分析图长边最多 1280px，不上传原视频或音频。逐条处理，失败不影响后续素材，支持重试和停止，保留已完成结果及手动修改。
   AI 识别画面文字和内容，不含音频识别；不按语言猜投放国家。角色性别结合多帧画面判断主要角色的呈现，多个主要角色标记为 MPP，无法判断时填 Others。其他无法判断的字段可留空，请结合自己的投放和业务规则校正。
5. API Key 默认只保留在当前标签页内存；主动勾选「在此浏览器记住 Key」才存入本地浏览器，可随时清除。其他配置、选项与日期序号保存在本地；文件与分析结果切换工具后保留，刷新或关闭页面后需重新导入。
   本地 Node 服务和 ChatGPT Sites 均通过同源接口转发火山请求，服务端不保存 Key 或媒体。纯静态部署时，AI 服务需要允许浏览器跨域。自定义 Chat Completions 服务直接从浏览器调用。
6. 可下载单条素材，或把勾选素材打包为 ZIP；文件内容保持原样，不改动原文件。CSV 清单记录所有当前素材的原名、新名及字段，便于复核，不包含 API Key。
   下载素材后记录该日期的后续序号，下一批自动续排；当前批预览名称保持稳定。导出 CSV 不推进序号，手动设置起始序号优先。

批量混剪：素材、队列与记录
1. 分别导入片头和成片，可选择多个本地视频或拖入文件。每组列表可勾选素材、设置开始/结束秒数及 0–2 倍音量，也可移除素材。
   单片头模式要求恰好选择 1 个片头，搭配所有选中的成片；全组合逐一配对两组素材；顺序配对要求两组选中数量相同，按列表从上到下配对。
2. 设置 MP4/MOV/WebM、720×1280/1080×1920/1280×720/1920×1080/1080×1080、24/30/60 fps、完整显示或铺满裁切、背景色、码率档和文件名前缀。
   「添加组合到队列」为每条任务保存当时的素材、裁剪、音量和输出设置。之后修改左侧设置不会改变已有队列；需要更新时移除旧任务，再添加新组合。
   一次最多保留 50 条待处理任务。点击任意组合可预览片头到成片的衔接；队列支持勾选、移除，显示待生成、生成中、已生成或失败状态。
3. 生成按队列逐项执行，单条成功直接下载，多条成功打包 ZIP。某条失败会显示具体原因并继续后续任务。
   取消后不自动下载未完成批次，已生成的结果仍可单独或打包下载；失败任务可重新选择后重试。
4. 默认跳过已生成/已完成记录，以及已在队列中的重复组合。组合标识来自源文件名、大小、修改时间和裁剪、音量、输出参数，未计算文件内容哈希；文件名前缀不参与去重。
   因此去重不是文件内容完全相同的证明。如需重新制作相同组合，可关闭跳过选项后添加。
5. 本地素材、队列和生成结果在当前标签页内保留，切换工具后仍可回来继续使用；刷新或关闭标签页后会丢失，需要重选文件。
   制作记录独立保存于当前浏览器 localStorage，最多保留 500 条，界面显示最近 50 条；支持标为完成、删除及 JSON 导入导出。
   记录 JSON 不包含源视频或生成文件。「已生成」「已完成」不等于已经下载或云端备份，长期保存必须下载视频文件。
   此工具仅做本地拼接，不含 AI 自动剪辑、报表分析或云端团队协作。

对话打字动画：三个设置标签页
1. 台词顺序：设置标题、左右方向和每句停留时间（0.2–10 秒），添加、删除、撤销最近一次删除、上移或下移台词。
   最多 20 条，每条最多 300 个字符；空白台词不参与动画。对方消息直接出现，自己的消息逐字输入；点击「定位」可查看该句画面。
   「批量粘贴」按行替换现有台词，可用「左:」「右:」或「A:」「B:」指定方向；没有标记时左右交替。
2. 画面键盘：自己的打字速度 1–30 字/秒，开始和结束停留各 0–10 秒；最后一句为自己时，可发送为气泡，也可完整保留在输入框。对方消息只占用设定的停留时长。
   键盘支持九宫格、QWERTY 或隐藏。在「画面键盘 → 语言模式」选择「English · 英语模式」，自动使用英文 QWERTY 键盘，输入框与发送按钮也切换为英文。
   英文支持字母、空格、数字与常见标点的按键高亮和键帽提示；自动模式按自己的台词匹配语言。可开关键帽提示和顶部返回栏。
   键盘仅用于视觉演示，中文逐字呈现，不是拼音输入法，也不含联想候选词。
   可选浅色、深色、自定义颜色或上传背景图；气泡字号 24–54 px，左右气泡和文字颜色独立设置。
3. 导出文件：选择 MP4（默认）、MOV 或 WebM，设置文件名、720×1280 或 1080×1920、24/30/60 fps；MP4/WebM 可选 4/6/12 Mbps。
   「导出动画」生成完整无声片段，与当前预览位置无关；MP4/MOV 按设定帧率逐帧生成，WebM 实时录制。「保存当前预览帧 PNG」只保存当前画面。
   MOV 使用 ProRes 4444，默认开启透明背景，可关闭。透明模式忽略背景颜色和背景图，但保留键盘、气泡和顶部栏自身底色；关闭后恢复原背景设置。
   棋盘格只表示预览中的透明区域，不会写入视频或 PNG。当前帧 PNG 与预览使用相同画面和真实透明度。ProRes 使用固定质量，码率随内容变化，不使用此处的码率档。
   参数、台词和背景图自动保存在当前浏览器；outputFormat 和 transparentBackground 也随草稿与项目 JSON 保存。导入 JSON 可跨设备继续编辑，背景图会压缩后嵌入项目。
   若提示自动保存失败，请手动保存项目 JSON。「恢复默认示例」会替换当前草稿，先保存需要保留的项目。

动画时间线预览
计时器、对话打字动画和选项动画，在画面下方均提供时间线。
点击播放/暂停；拖动蓝色进度条查看任意时刻，点击片段名称可跳转到片段起点。
左侧回到开头按钮将预览归零。未聚焦输入框或按钮时，也可用空格切换播放/暂停。
修改参数后保持暂停，预览位置保留；缩短时长时自动限制到新的结束位置。
导出始终生成完整动画，完成或取消后会恢复导出前的预览位置。

数据与运行方式
视频、图片加工及重命名打包在浏览器中完成，不访问参考网站。智能命名仅在用户允许并点击分析后，将抽帧图片发送到配置的 AI 服务；火山接口可经本应用服务转发，原视频和音频不上传。
收藏、对话动画草稿和混剪制作记录保存在当前浏览器的本地存储中。对话草稿包含台词、参数和背景图；混剪制作记录仅包含记录数据，不含媒体。
混剪素材、队列和生成结果在标签页会话内保留，切换工具不清空，刷新后丢失。其他工具的文件和未保存参数仅存在当前页面，刷新后需重新选择。
浏览器本地数据不在不同设备或不同网址间同步；备份或迁移时保存对话项目 JSON、混剪记录 JSON，并另外保存视频文件。
这是功能精简后的副本，没有修改原站，没有部署发布。

视频格式与运行限制
视频居中、批量混剪、对话打字动画、数字计时器和选项动画，五个视频工具均默认导出 MP4，也可选择 MOV 或 WebM。
MP4 使用 H.264，有声输入编码为 AAC；MOV 使用 ProRes 4444，保留 Alpha 通道，有声输入编码为 PCM。三个动画工具输出无声视频。
三个动画工具在 MOV 模式下默认开启透明背景，可关闭；视频居中默认透明留边并保留原视频画面。透明设置不会自动给源视频抠像，也不会把已有不透明画面变成透明。
动画的 MP4/MOV 按固定帧率逐帧生成；WebM 按动画时长实时录制。视频居中先按源视频时长合成，再按所选格式编码，耗时还受素材与设备性能影响。
MP4 依赖浏览器 WebCodecs 编码能力。推荐新版 Chrome / Edge；导出时会检测 H.264，以及有声视频所需的 AAC 支持，不支持时可改选 WebM。
MOV 由本地单线程 FFmpeg WebAssembly Worker 编码，需 HTTP/HTTPS 运行；file:// 双击模式不能导出 MOV，MP4/WebM 仍可在浏览器支持时使用。
FFmpeg wasm 约 31 MiB，随 vendor/ffmpeg 一起部署，运行时从本站加载，不使用 CDN。单线程版本无需 COOP/COEP 跨源隔离响应头。
ProRes 文件体积较大，生成耗时及内存占用受片段长度、分辨率和设备性能影响。逐帧 PNG 输入缓存累计上限为 256 MiB，超过时应缩短片段或降低分辨率；其他输入/输出超限会明确提示，建议分批导出。
MOV 是否能在目标播放器或剪辑软件中完整显示 Alpha，需在实际使用的软件和版本中验收；未声称已完成剪映兼容性测试。
实时录制时请保持页面在前台。输入视频能否解码取决于浏览器，推荐 H.264 MP4 或 WebM。
ZIP 不二次压缩媒体，单包上限 4 GB。大批量素材建议分批处理。
字幕为手动时间轴编辑，不含自动语音识别。AI 目前用于智能命名的画面字段识别，不含自动混剪、报表分析、云端团队服务或桌面下载工具。
